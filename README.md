## Why Property Managers (not just Realtors)

Realtor and property manager audiences overlap but don't substitute. Realtors run transactions; property managers run ongoing operations. Search intent differs:

- "Best AI for realtors" → seller/buyer lead gen, CMA, listing copy
- "Best AI for property managers" → tenant screening, rent collection, maintenance dispatch, lease management, owner reporting

A property manager running 50-500 doors needs a different stack than an agent closing 30 transactions/year. Buildium and AppFolio don't appear on realtor lists; Lofty and Follow Up Boss don't appear on PM lists. Distinct niche, distinct affiliate programs, distinct buyer persona.
